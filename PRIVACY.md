# Ember Launcher — Privacy Policy

_Last updated: October 28, 2026_

## The short version

Ember Launcher runs on your PC and keeps your data on your PC. There are no accounts, no analytics, no ads and no tracking.

## What Ember stores

Your game library (names, file paths, launch settings, groups), cover images you choose, your play sessions (start and end times), and your theme and consent choices. All of it is saved locally in %APPDATA%\ember-launcher\ and is never uploaded.

## How playtime is detected

To know when a game is running, Ember reads the file paths of running processes on your computer. This happens locally. Ember does not record, store or send the list of your other programs.

## Network use

The only network activity is checking GitHub for new versions and downloading updates from GitHub Releases. Like any web request, this lets GitHub see your IP address and standard request details, which GitHub handles under its own privacy statement. Ember sends no information about you, your games or your playtime.

## Your control

You can edit or remove any game inside the app. To erase everything, uninstall Ember and delete the %APPDATA%\ember-launcher\ folder.

## Changes and contact

If this policy changes, the new version ships with an update and the date above changes. Questions: https://github.com/Jellyt16/ember-launcher/issues
